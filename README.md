# termanat

Discover and learn Anatomy inside your terminal.

`termanat` is a TUI (terminal user interface) for exploring the human body —
bones, organs, muscles and more — all drawn in ASCII art.

## Features (planned)

- Browse body systems (skeletal, organs, muscular, ...)
- ASCII art illustrations with labeled parts
- Quiz mode to test your knowledge
